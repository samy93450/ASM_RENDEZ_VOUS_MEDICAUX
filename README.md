# ASM Rendez-vous Médicaux

Application iPhone installable avec icône ou photo du médecin/organisme, compte à rebours et rappels sonores.

## Publication sur GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Décompressez ce ZIP.
3. Envoyez tout le contenu à la racine de la branche `main`.
4. Ouvrez **Settings → Pages** dans GitHub.
5. Dans **Build and deployment**, choisissez **GitHub Actions**.
6. Attendez la fin de l’action **Publier ASM Rendez-vous Médicaux**.

## Installation sur iPhone

Ouvrez l’adresse GitHub Pages dans Safari, touchez **Partager**, puis **Sur l’écran d’accueil**. L’icône ASM Médical est déjà intégrée.

Pour des rappels fiables lorsque l’application est fermée, utilisez le bouton **Calendrier iPhone**. Chaque événement contient une alerte trois jours avant et une seconde alerte à l’heure du rendez-vous.

Les données personnelles restent enregistrées localement sur l’appareil.
